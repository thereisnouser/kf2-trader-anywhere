# Changelog

## 0.1.0

### Added
- Initial public source version of Trader Anywhere.
- Open all enabled trader pods during the trader phase.
- Access the standard trader menu from anywhere with the normal interaction key.
- Preserve native interaction prompts, hold-to-auto-buy, and nearby usable objects.
- Disable remote trader access during combat.
- Include a PowerShell script for compiling and brewing the UnrealScript package.

### Notes
- The internal package remains `W4AllTraders`.
- The mod is not officially whitelisted by Tripwire.
- The public source revision requires a fresh SDK build before distributing a binary.
