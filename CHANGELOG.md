# Changelog

## 0.1.0

First public source version of Trader Anywhere, based on the previously tested development build.

- Open all enabled trader pods during trader time.
- Open the trader menu remotely using the standard interaction key.
- Support native interaction prompts and hold-to-auto-buy.
- Preserve priority for nearby usable objects.
- Replicate trader phase state and per-player interaction triggers.
- Disable remote trading during combat.
- Include a Windows SDK build and brew script.

The internal package is still W4AllTraders. This version is not officially whitelisted. The public source revision requires a fresh SDK build before distributing a binary.
